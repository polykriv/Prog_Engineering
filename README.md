## №2
Класс итератор с гибкой настройкой и удобными применением

```
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```

### Результат
![Меню](https://github.com/polykriv/Prog_Engineering/blob/Tema_11/ScreenCod/2.png)

### Вывод:
Был создан класс-итератор CountDown с гибкой настройкой, реализующий методы iter() и next(). Такой подход позволяет кастомизировать поведение итератора, добавлять дополнительную логику и удобно использовать в различных сценариях, в отличие от простого итератора.

## №3
Генератор списка

```
a  = [i ** 2 for i in range(1, 5)]

print('a - ', a)
for i in a:
    print(i)

print('iter(a) - ', iter(a))
for i in a:
    print(i)
```

### Вывод:
Использован генератор списка (list comprehension) для создания последовательности квадратов чисел. Этот подход компактен и эффективен для создания новых списков на основе существующих итерируемых объектов. Функция iter() возвращает объект итератора для созданного списка.

## №5
Такой же счетчик, как и в первом задании, только это генератор и использует yield

```
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```

### Результат
![Меню](https://github.com/polykriv/Prog_Engineering/blob/Tema_11/ScreenCod/5.png)

### Вывод:
Реализован генератор с использованием ключевого слова yield, который создает обратный отсчет. Генераторы позволяют лениво вычислять значения по мере необходимости, экономя память. Функция-генератор сохраняет состояние между вызовами и продолжает выполнение с места последнего yield.

## №6
Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность "доставать" промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

fib_sequence = fib(200)
for i, num in enumerate(fib_sequence, 1):
    if i == 200:
        print(f"200-е число Фибоначчи: {num}")
        break
```

```
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

with open('fib.txt', 'w') as f:
    for i, num in enumerate(fib(200), 1):
        f.write(f"{num}\n")
        if i == 200:
            print(f"200-е число Фибоначчи: {num}")
```
